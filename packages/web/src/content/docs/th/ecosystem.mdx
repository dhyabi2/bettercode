ชุดโครงการชุมชนที่สร้างขึ้นบน NanoCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ NanoCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-nanocode](https://github.com/awesome-nanocode/awesome-nanocode) และ [nanocode.cafe](https://nanocode.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
